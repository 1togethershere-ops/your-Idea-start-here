# Sales Audit Dashboard — Netlify Deploy Package

สิ่งที่เกิดขึ้นในภาพที่ส่งมา: ไฟล์ `.jsx` ที่ผมเคยส่งให้เป็น **React component ดิบๆ**
มันต้อง "build" (แปลงเป็น HTML/JS/CSS ที่เบราว์เซอร์รันได้จริง) ก่อนถึงจะ deploy ได้
การอัปโหลดไฟล์ `.jsx` ตรงๆ ขึ้น Netlify เลยแสดงผลเป็นตัวหนังสือเปล่าๆ (โค้ดดิบ) แทนที่จะเป็นเว็บ

โฟลเดอร์นี้คือโปรเจกต์ React ที่ตั้งค่าให้ build ได้จริงแล้ว (ใช้ Vite) — ลองแล้วบิลด์ผ่านเรียบร้อย

## สิ่งที่เปลี่ยนจากไฟล์เดิม

- เพิ่ม `src/storagePolyfill.js` — จำลอง `window.storage` (ระบบเก็บข้อมูลที่โค้ดใช้อยู่)
  ด้วย `localStorage` ของเบราว์เซอร์ เพราะ `window.storage` ของจริงมีให้ใช้แค่ใน Claude.ai เท่านั้น
  **โค้ดใน App.jsx ไม่ต้องแก้อะไรเลย ยังใช้ `window.storage.get/set/...` เหมือนเดิมทุกจุด**

  ⚠️ **ข้อจำกัดสำคัญ**: `localStorage` เก็บข้อมูลแยกตาม "เบราว์เซอร์ในเครื่องนั้นๆ" —
  ถ้าสาขา A อัปโหลดข้อมูลจากคอมของตัวเอง สาขา B ที่เปิดเว็บนี้จากคอมอีกเครื่องจะ**ไม่เห็น**ข้อมูลเดียวกัน
  (คนละคนคนละเครื่อง = คนละชุดข้อมูล) ถ้าต้องการให้ทุกคนเห็นข้อมูลชุดเดียวกันจริง
  ต้องมี backend/database กลางจริงจัง (บอกได้ถ้าอยากให้ช่วยต่อยอดส่วนนี้)

## วิธี Deploy ขึ้น Netlify

### วิธีที่ 1 — ลากวางไฟล์ (เร็วที่สุด ไม่ต้องรู้จัก git)

1. เปิด terminal/command prompt ในโฟลเดอร์นี้
2. รันคำสั่ง:
   ```bash
   npm install
   npm run build
   ```
3. จะได้โฟลเดอร์ `dist/` เกิดขึ้นมา
4. ไปที่ [app.netlify.com/drop](https://app.netlify.com/drop)
5. ลากโฟลเดอร์ `dist` ทั้งโฟลเดอร์ไปวางในหน้านั้น — เสร็จเลย ได้ลิงก์เว็บทันที

### วิธีที่ 2 — เชื่อมกับ Git (แนะนำถ้าจะแก้ไขต่อเรื่อยๆ)

1. สร้าง repo บน GitHub แล้ว push โฟลเดอร์นี้ทั้งหมดขึ้นไป
2. ไปที่ Netlify → **Add new site → Import an existing project**
3. เลือก repo นั้น ตั้งค่า:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
4. กด Deploy — ทุกครั้งที่ push โค้ดใหม่ Netlify จะ build ให้อัตโนมัติ

## หลัง Deploy แล้ว

- เปิดลิงก์ Netlify ที่ได้ ควรเห็นแดชบอร์ดแสดงผลปกติ (ไม่ใช่ตัวหนังสือโค้ดแบบในภาพแล้ว)
- ปุ่ม "ส่งรายงาน & PDF" ที่เชื่อมกับ Google Apps Script (ตามที่ตั้งค่าไว้ก่อนหน้า) ยังทำงานเหมือนเดิม
  เพราะเป็นการยิง `fetch()` ไปยัง URL ภายนอก ไม่เกี่ยวกับ `window.storage`
